# SVG 绘图组件工作说明

## 在网站设计项目中的作用

本组件为 AI 提供“编辑 SVG → 渲染 PNG → 查看画面 → 修改并复查”的素材制作流程。它接收网站设计任务中的素材要求和参考图，输出可供网站使用的 SVG，以及按需保留的 PNG。

SVG 是正式、可编辑的源文件，PNG 用于视觉检查或图片交付。网站主项目根据自己的目录和框架接入这些素材；本组件不提供页面布局、交互逻辑或框架专用的 UI 组件。既有院徽、logo 及参考图属于当前仓库的设计内容，流程可用于其他 SVG 绘图任务。

AI 的操作约定、素材保护和清理授权见 [AGENTS.md](AGENTS.md)。

## 组件构成与环境

| 文件 | 作用 |
| --- | --- |
| `AGENTS.md` | AI 入口，定义任务边界、检查步骤和文件管理约定 |
| `SVG工作流声明.md` | 解释组件作用、命令行为和网站接入方式 |
| `svg` | 本地命令，负责渲染预览、清理临时目录和显示帮助 |
| `package.json`、`package-lock.json` | 声明并锁定渲染依赖 |
| `.gitignore` | 排除依赖目录、临时文件和系统杂项文件 |

制作环境需要 Node.js 18 或更新版本。唯一的直接渲染依赖是 `@resvg/resvg-js`，无需启动服务或执行构建。新环境或缺少依赖时，在组件根目录运行：

```sh
npm ci
```

组件根目录是 `svg` 与 `package.json` 所在目录。嵌入网站仓库后，以下命令仍在该目录执行，不要将网站仓库根目录与组件根目录混淆。

## 编辑、渲染与视觉检查

先创建或修改目标 SVG，再执行渲染。以下 `素材/logo.svg` 是示例路径，使用时替换为实际文件路径；路径含空格时保留引号。

```sh
# 按 SVG 自身尺寸渲染预览
./svg render "素材/logo.svg"

# 指定 PNG 输出宽度，高度按比例缩放；不修改 SVG 源文件
./svg render "素材/logo.svg" --width 1600

# 查看命令帮助
./svg help
```

`--width` 必须是正整数。命令失败时会输出错误并以非零状态退出；缺少依赖时按提示执行 `npm ci`。若环境未保留脚本的可执行权限，可以使用 `node ./svg render "素材/logo.svg"` 等等价形式。

渲染成功后，命令仅输出生成 PNG 的绝对路径。AI 必须把这个路径交给图片查看工具（如 `view_image`），实际查看画面，检查轮廓、比例、颜色、对齐、裁切和文字。发现问题后修改 SVG，重新渲染并查看，直到本次要求得到满足。无法查看时，应说明检查尚未完成。

渲染行为如下：

- 不指定宽度时，按 SVG 自身尺寸渲染；未绘制背景的区域保留透明效果。
- 输入路径相对于命令执行时的工作目录，也可使用绝对路径。
- 预览始终写入组件根目录的 `.tmp/`；文件名包含由源文件绝对路径生成的标识。
- 同一源文件的后续渲染覆盖原预览，包括改用其他输出宽度的情况；不同目录下的同名 SVG 使用不同预览路径。
- 渲染只生成 PNG，不修改 SVG，也不代替视觉检查。

## SVG 内容与网站接入

以自包含、可编辑的 SVG 为主要交付形式。图形使用矢量元素；确需使用位图时，采用内嵌 data URL，避免交付物依赖本机路径。预览命令使用 resvg，不额外加载外部图片，也不执行网页脚本。

渲染时会加载系统字体，因此不同机器的文字效果可能不同。需稳定复现的文字可转为路径，同时保留仍需编辑的文字源文件。PNG 预览用于检查静态外观；网站中的实际展示尺寸、布局和交互由主项目接入后检查。

网站可将 SVG 作为静态图片引用，或按自身框架要求内联使用。Node.js、`svg` 命令和渲染依赖服务于素材制作，网站展示已交付的 SVG 或 PNG 时不需要调用它们。

## 正式交付与临时文件

正式 SVG、用户原始素材、参考图以及需交付的 PNG 均放在 `.tmp/` 外。沿用主项目指定的素材目录或现有存放位置；无需为了使用此流程调整网站目录结构。

可丢弃的草稿、预览和测试素材统一放在 `.tmp/`。需要保留预览 PNG 时，先根据命令输出的绝对路径将其复制到正式目录，再清理：

```sh
./svg clean
```

清理命令删除组件根目录的整个 `.tmp/`，下次渲染会自动重建。任务结束前完成清理，并向用户提供正式交付文件的路径及实际完成的检查结果。提交或打包到 GitHub 时，`node_modules/` 和 `.tmp/` 按 `.gitignore` 排除；保留依赖声明、锁文件和正式素材。
